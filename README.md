## Platform Overview

**Nexus** (Continuum) is a revolutionary digital platform designed to solve a critical problem in India's service industry: **finding reliable, trustworthy local service providers**.

### The Problem
- Citizens struggle to find reliable plumbers, electricians, cleaners, and other service professionals
- No centralized trust mechanism for local service providers
- Word-of-mouth is unreliable and time-consuming
- Risk of hiring unverified or fraudulent service providers
- Service providers lack a platform to build credibility and reach customers

### The Solution
Nexus is a **trust-based service booking platform** that:
- *Connects verified service providers with customers
- *Implements a multi-tier verification system adapted for India
- *Uses ML/CV technology for fraud prevention and quality assurance
- *Builds reputation through transparent reviews and job history
- *Creates employment opportunities for local service professionals
- *Provides engaging 3D UI for modern user experience

## Platform Theme & Vision

### Core Philosophy
**"Trust Through Transparency, Verification Through Innovation"**

The platform operates on three fundamental pillars:

#### 1. **Trust-Based Ecosystem**
- Every interaction is tracked and verified
- Reputation scores based on real job history
- Progressive badge system (Verified → Trusted → Top Pro)
- User reviews and ratings are integral to provider credibility
- Community-driven quality assurance

#### 2. **India-Centric Verification**
- Acknowledges that most Indian service workers learn through **practical experience**, not formal certifications
- Focuses on **identity verification, trust-building, and practical proof** rather than rigid qualifications
- Accepts diverse proof methods: Aadhar, PAN, utility bills, work samples, video demonstrations
- Flexible verification aligned with India's informal economy

#### 3. **AI-Powered Quality & Security**
- Machine Learning for fraud detection and spam review identification
- Computer Vision for ID document verification and face recognition
- Real-time liveness detection during video verification
- Automated quality analysis from work proof images
- Location verification through GPS and geolocation

### Target Market
- **Primary:** Urban and semi-urban India (Tier 1 & Tier 2 cities)
- **Secondary:** Any market with high demand for local services and trust deficit
- **Timeframe:** MVP launch within 3-6 months, national expansion within 18 months

## Types of Users

### 1. **Customers**
*End-users seeking local services*

**Who:** Homeowners, renters, office managers, event organizers
- **Registration:** Simple phone number + basic profile
- **Capabilities:**
  - Search services by category and location
  - View provider profiles with ratings and reviews
  - Book services with scheduling
  - Track booking status in real-time
  - Leave detailed reviews and ratings
  - Maintain booking history
  - Rate service quality (1-5 stars with comments)

**Customer Journey:**
```
Search Service → View Providers → Book → Communicate → Receive Service → Review → Build History
```

---

### 2. **Service Providers**
*Local professionals offering services*

**Who:** Plumbers, electricians, cleaners, carpenters, painters, mechanics, beauty professionals, tutors, etc.

**Verification Status Levels:**
- *Verified* - Identity + Address verified (entry level)
- *Trusted* - 20+ jobs completed with 4.0+ rating
- *Top Pro* - 50+ jobs, 4.5+ rating, zero complaints

**Capabilities:**
- Create detailed service profile with expertise, pricing, and availability
- Upload work portfolio (photos, videos, testimonials)
- Accept or decline bookings
- Manage job schedule and customer communication
- Update real-time availability
- Build reputation through customer reviews
- Access earnings dashboard and payment history
- View analytics on profile views and booking requests

**Provider Benefits:**
- Access to verified customer base
- Professional reputation building
- Regular income through bookings
- Portfolio showcase for skill credibility

**Provider Requirements:**
- Aadhar Card (mandatory ID proof)
- Address proof (utility bill or Aadhar)
- Work proof (photos of past work, customer references, or skill video)
- Phone verification by Verifier

---

### 3. **Verifiers**
*Trust intermediaries managing quality control*

**Who:** Pre-vetted individuals (trainable professionals or retired professionals with integrity)

**Responsibilities:**
- Review and verify service provider applications
- Conduct identity and background checks
- Perform phone/video verification calls with providers
- Analyze work proof documents and quality
- Approve/reject providers with appropriate badges
- Escalate fraud attempts or suspicious applications
- Maintain verification records and audit trails
- Handle disputes and quality complaints

**Capabilities:**
- Dedicated Verifier Dashboard
- Batch verification workflow
- Document OCR integration (auto-extract Aadhar, PAN, address)
- Work proof image analysis
- Communication templates for verification calls
- Fraud detection alerts
- Performance metrics (verification accuracy, avg verification time)

**Requirements to Become Verifier:**
1. **Application:** Resume, Aadhar, PAN, identity photo
2. **Background Check:** Admin verifies identity and no criminal record
3. **Interview:** Video/phone call to assess communication and reliability
4. **Training:** Platform onboarding and verification process training
5. **Trial Period:** 2 weeks supervised work before full access

---

### 4. **Admin**
*Platform administrators and governance authority*

**Who:** Nexus team and authorized platform managers

**Responsibilities:**
- Verify and approve Verifiers (hire, monitor, remove)
- Handle platform disputes and complaints
- Moderate content and reviews
- Manage system settings and configurations
- View comprehensive platform analytics
- Manage payment and commission structures
- Monitor platform health and security
- Set verification policies and criteria
- Generate reports for stakeholders

**Capabilities:**
- Master Admin Dashboard
- Verifier management interface
- Dispute resolution system
- Platform analytics and KPIs
- Payment processing and settlements
- User account management
- System logs and audit trails
- Feature configuration and deployment

## Technology Stack

### **Frontend**
| Technology | Purpose | Explanation |
|-----------|---------|-------------|

| **Firebase** | Authentication | Backend-as-a-service for phone/email authentication and real-time notifications |

### **Backend**
| Technology | Purpose | Explanation |
|-----------|---------|-------------|
| **Node.js** | Runtime | JavaScript runtime for building scalable server-side applications |
| **Express.js** | Web Framework | Lightweight, flexible framework for building REST APIs and handling HTTP requests |

### For Service Providers

| Step | What Happens | Purpose |
|------|--------------|---------|
| 1. **Signup** | Provider registers with phone number and basic info | Initial account creation |
| 2. **Identity Proof** | Upload Aadhar Card + photo | Verify real identity (fraud prevention) |
| 3. **Address Proof** | Upload utility bill or Aadhar | Verify service area legitimacy |
| 4. **Work Proof** | Submit any one: photos, references, or skill video | Demonstrate actual service capability |
| 5. **Phone Verification** | Verifier calls to confirm details | Human verification against script fraud |
| 6. **Approval** | Verifier approves and awards badge | Goes live on platform |

**Technology Used:**
- Tesseract.js extracts Aadhar data automatically
- TensorFlow.js matches face with ID photo
- OpenCV.js analyzes work quality from images
- MediaPipe validates skill demonstration in videos

### For Verifiers (by Admin)

| Step | What Happens | Purpose |
|------|--------------|---------|
| 1. **Application** | Verifier applies with resume, Aadhar, PAN, photo | Initial screening |
| 2. **Background Check** | Admin verifies identity and criminal record check | Ensure trustworthiness |
| 3. **Interview** | Video/phone call assessment | Evaluate communication and judgment |
| 4. **Approval** | Admin grants verifier dashboard access | Onboard to platform |
| 5. **Trial Period** | 2-week supervised work with full access | Monitor quality and consistency |
| 6. **Full Access** | Complete independence after successful trial | Ready for production |

### Verification Badges

## Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn
- MongoDB Atlas account
- Firebase project
- Razorpay account (for payments)

### Installation

1. **Clone the repository:**
```bash
git clone <repository-url>
cd nexus
```

2. **Install dependencies:**
```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

3. **Setup environment variables:**

**Backend (.env):**
```
MONGODB_URI=<your-mongodb-atlas-connection-string>
JWT_SECRET=<your-jwt-secret>
FIREBASE_API_KEY=<your-firebase-api-key>
RAZORPAY_KEY_ID=<your-razorpay-key>
RAZORPAY_KEY_SECRET=<your-razorpay-secret>
PORT=5000
NODE_ENV=development
```

**Frontend (.env.local):**
```
VITE_API_URL=http://localhost:5000
VITE_FIREBASE_API_KEY=<your-firebase-api-key>
VITE_RAZORPAY_KEY_ID=<your-razorpay-key>
```

4. **Start the application:**
```bash
# Backend terminal
cd backend
npm run dev

# Frontend terminal (new terminal)
cd frontend
npm run dev
```

5. **Access the application:**
- Frontend: http://localhost:5173
- Backend API: http://localhost:5000

### Running in Production
- Deploy backend to Render or Railway
- Deploy frontend to Vercel
- Configure MongoDB Atlas for production
- Enable Firebase security rules
- Setup Razorpay production credentials
